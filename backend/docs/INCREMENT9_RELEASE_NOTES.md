# Increment 9 Release Notes

**Feature:** Legal Citation & Authority Verification Engine  
**Database revision:** `0012_citation_verification`  
**API namespace:** `/citations`

### Included
- Citation extraction and normalization.
- Repository identity matching.
- Pinpoint checks against structured legal provisions and judgment paragraphs.
- Event-backed authority status.
- Workspace-scoped persistence and verification history.
- API documentation and unit tests.

### Not included
- Live internet/court-database lookup.
- Automatic case-name resolution or parallel-citation reconciliation.
- AI proposition-to-passage entailment assessment.
- Comprehensive subsequent-treatment research.
- Automatic amendment consolidation or historical-law reconstruction.
- Resolution of Increment 8's deferred authenticated review API issue.
